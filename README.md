# Hospital Big Data Platform: Hive, Hadoop & Google Cloud Dataproc

Big Data project that designs and implements a hospital database on a distributed cluster, using Apache Hive on Hadoop deployed through Google Cloud Dataproc, with Spark-based analysis.

## Tech Stack
Apache Hadoop · Apache Hive · Apache Spark · Google Cloud Dataproc · HiveQL

## Highlights
- Designed a hospital data schema and loaded it into HDFS.
- Implemented tables and analytical queries with HiveQL.
- Deployed and ran the cluster on Google Cloud Dataproc.
- Performed Spark-based processing and documented the results.

- `spark_report.docx`: Spark report
